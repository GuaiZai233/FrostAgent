# OneBot v11 接入

FrostAgent 的 OneBot 适配器提供 WebSocket 服务端。由上游 OneBot v11 客户端主动建立反向 WebSocket 连接。

## 配置步骤

1. 在 FrostAgent 创建实例，配置主对话模型并启用。
2. 在概览复制 OneBot 地址。
3. 在上游启用反向 WebSocket 客户端，填写地址。
4. 确认上游提供消息事件以及 `get_msg`、发送消息等所需动作接口。
5. 用私聊和群聊真实 @各验证一次，在日志中确认收发与动作回执。

```text
ws://127.0.0.1:1234/instances/<实例ID>/ws/onebot
```

实例 ID 必须使用真实值。远程或分容器接入时替换主机地址，参见[部署与网络](../guide/deployment)。当前每个实例的 OneBot 和 AstrBot 入口均可用，旧 `ENABLE_ONEBOT_ADAPTER` 和自定义路径配置不用于关闭或改名入口。

## 群聊与消息能力

真实 @机器人、名称 / 别名等信号交由 FrostAgent 的[群聊回复策略](../usage/group-chat)判断。后台群聊摘要需要上游转发普通群消息，连接成功不代表上游发送了所有事件。

引用追溯会按需使用 `get_msg` 获取旧消息。上游不支持该动作、消息已过期或不可访问时，追溯会停止；这不等同于普通文字消息发送失败。

发送消息需要正确返回 `echo` 对应的动作结果。`ONEBOT_ACTION_TIMEOUT` 默认 `10s`。上游没有返回确认、返回非成功状态或连接断开时，不能把工具发起请求视作成功投递。

## 常见问题

| 现象                     | 检查                                                       |
| ------------------------ | ---------------------------------------------------------- |
| 连接 404                 | 实例 ID、`/instances/` 前缀、`/ws/onebot` 路径与目标端口   |
| 已连接但不回复           | 实例启用状态、主对话模型、群聊开关、真实唤醒信号与安全状态 |
| 发送超时                 | 上游动作支持、回执 `echo`、权限与网络                      |
| 直接对话能用，上游不能用 | 上游可达地址、上游协议格式、代理与平台权限                 |

FrostAgent 负责智能体逻辑；账号登录与实际平台接入由 OneBot 上游实现。
