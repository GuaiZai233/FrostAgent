# 记忆管理

FrostAgent 用长期记忆保存值得在后续对话中召回的信息，同时使用会话历史和群摘要维持短期连续性。长期记忆与群摘要不是完整聊天记录。

## 记忆如何形成

- 从私聊对话中自动提取，按实例配置的累计轮数批量执行。
- 从群聊压缩快照提炼长期信息。
- 用户通过对话明确要求记住内容，由工具和可信会话上下文处理。
- 管理员在控制台维护条目，或执行反思整理。

记忆提取和反思依赖模型路由器中的相应工作负载。自动提取默认最小累计 3 轮、最大累计 5 轮；调整后应在真实会话中验证，不使用模拟连接测试持久化写入。

## 作用域与归属

| 场景                       | 边界                                              |
| -------------------------- | ------------------------------------------------- |
| 私聊                       | 按用户隔离，只在当前实例的对应用户作用域召回      |
| 群聊                       | 按群隔离，使用群 ID 区分，不走公开 / 私有共享路径 |
| 群内个人自述               | 使用可信发送者的 QQ 归属；昵称和群名片是展示信息  |
| 第三方说法、群规、多人关系 | 归入群作用域，不能仅凭提到某个人就归到其个人名下  |

同一个人出现在两个群中，不意味着两群记忆自动共享。群名片也不能直接变成 Bot 对该人的称呼。

## 来源与图片

记忆可以保留原文、展示摘要、证据、源消息 ID 和源发送者 ID。摘要帮助阅读，原始证据用于核对。

来自图片识别的条目保留图片来源标记，显示「（原source为图片形式）」。图片中的第一人称文字不等于上传者的自述，也不能把图片识别结果作为用户亲口说过的话。

## 控制台操作

在「记忆管理」中检索条目、查看归属与来源，按页面提供的编辑和删除操作纠正错误。检查群档案和反思归档时，确认当前实例与群 ID。

反思会整理或合并记忆；合并来源保留在归档中，归档不参与正常检索注入。群摘要用于最近话题延续，新摘要不作为普通长期记忆条目写入。

发现错误记忆时，先核对证据，再修正或删除。清理会话不会自动删除所有长期记忆；长期记忆修改也不会自动重写历史消息。

## 备份与导入

使用「系统设置 → 备份与还原」下载 `memory.json`，或下载包含记忆、档案、归档的全量 ZIP。记忆导入按 ID 合并，同 ID 跳过，现有群档案优先；不同 ID 仍可能表达相同内容，需要人工查重。

当前运行时使用 SQL，旧 `agent export/import/list/stats` 命令只操作 JSON 文件，不能作为当前数据库的备份工具。
