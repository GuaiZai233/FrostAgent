# 直接对话

「直接对话」是内置的 WebSocket 协议模拟器。无需连接真实上游，就能测试当前实例的模型与人格。

## 使用步骤

1. 选择已经启用、主对话路由可用的实例。
2. 选择 OneBot 或 AstrBot 协议。
3. 选择私聊 / 群聊，设置测试发送者；AstrBot 还可以设置下层平台类型。
4. 群聊场景填写群信息，并按需要启用模拟唤醒。
5. 连接后发送消息，检查气泡、连接状态与实例日志。

修改场景后可以重新连接；页面提供断开和清空聊天记录操作。连接使用管理页面同源路径，不需要在浏览器中直接连接外部 `1234` 端口。

## 「断电全丢」模式

模拟连接带有 `mock=true`，会话使用连接级独立命名空间。断开时取消在途工作、清理临时会话并释放相应沙箱资源，服务重启也不会恢复。

模拟模式允许只读召回长期记忆，但不更新召回元数据；禁止记忆写入与反思，跳过自动提取、群摘要落盘和贴图摘取。管理员指令不执行真实运维操作，安全评估采用 dry-run，不改变真实用户的封禁与违规状态。Alcyone 计费也会跳过。

`ban_user` 工具在模拟模式下可保存 `mock` 平台命名空间的访问锁与审计，和真实平台用户隔离；断开连接并不删除这些记录。

模拟模式仍会调用模型服务；MCP 业务工具与隔离沙箱可能执行实际外部请求。它不能替代外部工具的权限控制或真实平台联调。ActionsCat 的执行和变更工具在模拟模式下被拦截。

## 适合验证什么

| 可以验证               | 需要正式接入验证             |
| ---------------------- | ---------------------------- |
| 模型路由、人格和上下文 | 平台账号与发送权限           |
| 协议事件与回复转换     | 上游实际回执与图片可达性     |
| 群聊模拟与部分工具链   | 真实身份授权、管理员指令     |
| 安全 dry-run 判定      | 持久化记忆、群摘要、真实计费 |

连接失败时，检查实例状态和代理 WebSocket 支持；会话断开后的丢失属于预期行为。
