# 群聊与回复策略

群聊中，消息进入背景上下文与触发 Bot 回复是两件事。持续转发普通群消息可以让实例了解最近讨论，并不表示每条消息都会触发主对话。

## 显式唤醒

- 真实 @机器人。
- 文本中出现 `BOT_NAME` 或 `BOT_ALIASES` 中的名称。
- 引用机器人等协议支持的唤醒信号。

`GROUP_REPLY_ON_MENTION` 默认 `true`；设置为 `false` 时，当前适配器的群聊回复路径会直接关闭，包括主动回复。`ENABLE_AT_IN_GROUP_MSG` 控制回复时是否 @发送者，`ENABLE_REPLY_IN_GROUP_MSG` 控制回复是否引用原消息，二者不负责识别管理员身份。

AstrBot 的自身唤醒词与命令前缀不会自动成为 FrostAgent 唤醒词；名称唤醒需要插件将消息转发给后端。

## 主动回复

在「Bot 服务端设置」打开主动回复，并设置概率：

| 设置                               | 含义                                          |
| ---------------------------------- | --------------------------------------------- |
| `ENABLE_PROACTIVE_REPLY`           | 是否开启                                      |
| `PROACTIVE_REPLY_PROBABILITY`      | `0` 关闭；开启后有效概率区间为 `0.01`～`1.00` |
| `ENABLE_PROACTIVE_REPLY_WHITELIST` | 是否限制为指定群                              |
| `PROACTIVE_REPLY_GROUP_WHITELIST`  | 允许群号，英文逗号分隔                        |

开启白名单但列表为空时，没有群获准主动回复。白名单限制主动回复，不改变真实 @或名称唤醒的普通回复规则。

概率命中会触发对话，模型仍可以判断不适合发言并选择静默。它是消息驱动的参与策略，不是定时发消息。日志会记录主动回复触发信息，便于确认实际策略是否命中。

## 戳一戳唤醒

在「Bot 服务端设置 → Bot 行为与回复策略」开启「允许发送戳一戳行为」，填写可选附加文本和冷却时间，再保存。默认关闭，附加文本为空，冷却默认 30 秒，允许 0～86400 秒；0 表示不等待冷却。

仅处理目标为当前 Bot 的真实 QQ 戳一戳通知，不处理 Bot 自己戳自己，也不在模拟会话中启用。空附加文本传给模型的消息为「（用户戳了戳你）」，填写文本后追加到该消息中。该设置控制收到戳一戳后的唤醒，不会让 Bot 主动发送平台戳一戳动作。

冷却按 Bot 和会话区分，每个群独立且全群共享，私聊分别计算。仍遵守群聊回复总开关、安全检查、主对话路由和 Bot 连续对话限制；开启计费时按普通对话归触发用户结算。通知回复不会引用不存在的平台消息。

OneBot 上游需要转发 `notice/notify/poke` 通知。AstrBot 使用插件 0.1.4 或更新版本，aiocqhttp 会转发目标为当前 Bot 的通知，即使未开启普通群消息全部转发。功能关闭、冷却中、路由禁用或连接失败时不会回落到 AstrBot 默认 LLM。

## 引用链

`ENABLE_QUOTE_TRACE` 默认开启，`QUOTE_TRACE_DEPTH` 默认 5，可设置 1～10。后端按需回查引用消息，遇到不可访问消息时停止。引用内容保留来源，不应被当作当前发送者的原话。

## 限制 Bot 互相循环

在设置页的 Bot 用户 ID 列表逐项添加其他 Bot，保存后写入 `BOT_LOOP_USER_IDS`；可用 `platform:ID` 限定平台。`BOT_LOOP_MAX_TURNS` 默认 3。

- `soft`：超限时注入静默建议，模型负责选择是否停止。
- `hard`：超限后静默丢弃相应 Bot 输入。

其他发送者介入会打断连续计数。AstrBot 关闭普通消息转发时，需要新版插件的打断标记维持该行为。

## 背景上下文与记忆

群聊使用滚动压缩、未压缩原消息和按群隔离的长期记忆。`GROUP_COMPACT_BUFFER_SIZE` 默认 20，最小触发间隔默认 `30s`，原消息临时上下文预算默认 12000 字符。群压缩与记忆提取需要配置对应模型路由。

可在[会话与 Prompt](./sessions)查看实际摘要与注入上下文，在[记忆管理](./memory)检查被提取的事实与来源。提高主动回复频率和缩短压缩间隔都会增加模型调用量。
