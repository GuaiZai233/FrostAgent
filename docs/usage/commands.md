# 管理员指令

管理员指令由后端直接解析执行，不依赖模型理解。先在当前实例设置 `ADMIN_QQ_IDS`；空列表表示无人有管理员权限。多个 ID 可以用英文逗号分隔。

## 使用条件

指令消息需要真实 @当前机器人，并由已配置管理员发送。昵称、群名片、Bot 名称唤醒、引用旧消息或文本里的 `@` 都不能替代结构化真实 @；私聊也不自动免除该条件。

模拟连接不会执行这些运维指令。需要在真实适配器消息中验证。

## 指令表

默认前缀为 `/`。下面的 `<用户ID>` 需要替换为目标平台的实际 ID：

| 指令              | 行为                                     |
| ----------------- | ---------------------------------------- |
| `/reset`          | 重置当前会话与上下文，删除相关持久化摘要 |
| `/ban <用户ID>`   | 锁定该平台用户的全局 FrostAgent 访问权限 |
| `/unban <用户ID>` | 解除该用户的全局访问锁                   |
| `/compact`        | 立即压缩总结当前会话，需要可用压缩路由   |
| `/reflect`        | 触发当前作用域的记忆反思                 |

`ban` 是 FrostAgent 访问封禁，不是聊天平台的群禁言。不能封禁当前调用者或当前实例配置的管理员。全局访问锁跨实例生效；被锁定的管理员也不能通过普通消息指令绕过锁，需要有管理权限的人在控制台处理。

## 自定义前缀

在「系统设置 → 指令设置」修改 `ADMIN_COMMAND_PREFIX`。符号前缀可以紧贴指令，单词前缀需要空白分隔：

```text
/reset
execute reset
```

前缀只作用于当前实例，留空使用默认 `/`。页面会提供按当前前缀格式化的指令示例。

## 指令没有执行

先确认真实 @、当前实例的管理员 ID、前缀和参数，再检查实例启用状态、安全访问锁与日志。没有管理员权限的指令候选会被静默处理；不要把它当作模型回复故障。

`reset` 不清空全部长期记忆。需要整理长期记忆时使用[记忆管理](./memory)，删除实例数据前使用[备份与还原](../operations/storage)。
