# 控制台与实例

控制台默认位于 `http://127.0.0.1:8080`。先通过侧边栏底部的「实例管理」创建或选择实例，再操作实例页面。首次启动不会自动创建实例，刷新页面后需要重新选择。

## 页面导航

| 页面          | 用途                                           |
| ------------- | ---------------------------------------------- |
| 概览          | 查看运行状态、版本与适配器地址，启用或停用实例 |
| 模型路由器    | 管理共享供应商和模型、当前实例路由与群级覆盖   |
| 记忆管理      | 检索和维护长期记忆、群档案与归档               |
| 人格设定      | 编辑系统提示词和示例对话                       |
| 会话与 Prompt | 查看会话、群摘要及请求上下文                   |
| 表情包摘取    | 管理贴图、描述与召回次数                       |
| MCP服务器     | 配置 MCP 连接、同步工具目录和启停工具          |
| ActionsCat    | 检查自动化服务、动作、构建与运行               |
| 直接对话      | 用临时 WebSocket 模拟会话联调                  |
| 日志查询      | 按类型检查模型请求、工具调用和运行错误         |
| 系统设置      | 数据库、备份、Bot 服务端、网页外观和指令设置   |
| 安全控制      | 全局安全模式、访问锁和审计                     |

## 实例生命周期

- **创建**：分配新 ID、默认停用，初始化实例设置和示例对话。
- **选择**：决定当前控制台操作的实例，不会因此启用它。
- **启用**：启动实例运行时；要先准备可用模型路由。
- **停用 / 重启**：会中断连接和在途工作；完成配置后重新连接上游。
- **覆盖配置**：从其他实例复用设置、模型路由、MCP 与示例对话；目标现有配置会被覆盖，密钥与凭据来源不复制。该操作不等于克隆全部记忆和贴图。
- **删除**：先暂停实例并提供备份，再确认永久删除设置、记忆、摘要、贴图等实例数据。删除前下载存档。

实例 ID 用于 API 和适配器路由。实例名称只是显示标签，改名后不需要改 WebSocket 路径；从备份还原出的新实例则有新 ID，需要重新配置上游地址。

## 哪些配置会影响其他实例

实例默认路由、人格、群策略与 MCP 配置只影响当前实例。共享供应商、密钥与模型发布后会影响所有引用它们的实例。安全模式、访问封禁、监听地址和数据库选择也属于全局配置。

当前 SQL 模式保存实例设置后自动应用，必要时重新创建运行时，无需额外手动重启；重建会中断连接和在途任务。应用失败时恢复旧设置并报告错误。全局设置由控制面尝试自动应用，监听或连接失败时按页面和日志中的实际结果处理。

查看数据或执行修改前，确认页面中显示的实例名称与 ID。
