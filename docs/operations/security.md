# 安全控制

「安全控制」管理全局安全模式、用户访问锁与审计记录。主体使用规范化 `(平台, 用户ID)`，QQ 的 OneBot 与 AstrBot aiocqhttp 接入共享 `qq` 身份；昵称和模型文本不能声明身份。

## 三种模式

全局 `SECURITY_CONTROL_MODE` 支持：

| 值               | 行为                                                                 |
| ---------------- | -------------------------------------------------------------------- |
| `off`            | 跳过语义审查，已存在的访问锁仍在入口生效                             |
| `simple`（默认） | 保留访问控制与受限管理工具，不进行全链路 LLM 语义分类                |
| `aggressive`     | 通过 LLM 安全网关审查直接输入、间接上下文、工具参数 / 结果与模型输出 |

开启 aggressive 前配置可用的反思模型路由；安全网关使用该路由。分类器未配置、超时、网络错误或返回无效结构时，会阻断相应请求或隔离辅助上下文，不会降级为本地规则放行。

## 访问锁与审查故障

手动封禁在全部实例生效，可由有权限的管理者在控制台解除，或使用[管理员指令](../usage/commands)。模型 / 工具输出和引用上下文不能直接把无关用户当作违规者惩罚。

语义审查区分提示、过滤、阻断与重复严重违规的累计处理。分类器或存储故障会按故障处理，不累计用户违规次数，也不因为基础设施故障自动封禁用户。

直接对话的语义审查使用 dry-run，不累计真实用户的违规状态或持久化该次审查。若模型调用 ban_user 工具，后端仍会保存 mock 平台命名空间的访问锁和审计，不影响真实平台用户。测试结果仍受所选模式和模型路由影响。

## 管理面与工具权限

全局安全模式控制智能体路径；管理面认证、ActionsCat 外部服务 Token、消息接口 Token 和平台管理员身份分别配置。

MCP 服务器由管理员配置，模型只调用已暴露的业务工具。模型 Shell 命令只交给外部隔离沙箱；沙箱不可用时失败，不回退到宿主机。第三方业务工具仍需在其服务端限制自身权限。

## 管理面认证

普通构建的远程管理 API / RPC 统一要求控制令牌，覆盖设置、实例生命周期、数据库切换、备份、日志和业务管理服务。`MCP_CONTROL_TOKEN` 优先，未设置时兼容 `ADMIN_TOKEN`；`ALLOW_REMOTE_MCP_MANAGEMENT` 无法绕过统一鉴权。

1. 在本机「Bot 服务端设置 → 安全与权限」配置「管理控制令牌」并保存。
2. 远程浏览器打开「系统设置 → 前端设置」，填写相同令牌。
3. 网页将令牌存入当前 Origin 的 localStorage，并为管理请求附加 `Authorization: Bearer <令牌>`；换域名或清理浏览器存储后需重新填写。
4. 自建客户端也须携带该请求头。不要把令牌放入 URL、公开日志或截图。

可信回环访问默认免令牌；`MCP_ENFORCE_LOCAL_TOKEN=true` 时本机也要认证。反向代理保留公共 Host 或转发标识；若代理同时改成回环 Host 并清空转发标识，必须强制本机令牌，避免把远程请求误判为本机。

[容器构建](../guide/docker)通过数值回环管理监听和共享网络命名空间隔离入口，由整个公开域名上的 Cloudflare Access 负责外部认证。Tunnel 能连通不代表 Access 策略已生效。该构建信任的是实际回环 connector 连接，不是任意请求自报的 Cloudflare Header；显式开启的本机强制令牌仍须提供。

## 排障

在审计和系统日志中检查主体、阶段、错误类型与评估 ID。先区分用户内容被阻断、用户已锁定和审查服务故障，再采取解锁、调整请求或修复模型连接等对应操作。

备份访问锁和审计需要单独导出全局安全 JSON。日志和 Prompt 可能包含业务内容，公开排障前检查并移除敏感数据。
