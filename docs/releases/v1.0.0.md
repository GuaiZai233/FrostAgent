# FrostAgent v1.0.0

## 分发方式

本版本提供源码，支持从 GitHub Release 的 Source code 归档或 `v1.0.0` tag 获取。需要自行构建；不附带预编译程序，也不发布预构建 Docker 镜像。仓库的 Dockerfile 和 Compose 可用于本地构建部署。

本文件是发布说明源稿；版本是否已发布以 [GitHub Releases](https://github.com/GuaiZai233/FrostAgent/releases) 为准。

## 主要能力

- Go 后端与内嵌 Web 管理界面，支持多实例配置、人格提示词和对话示例。
- OneBot 反向 WebSocket 与 AstrBot 适配，提供群聊、私聊、主动回复及戳一戳唤醒。
- 共享模型供应商、实例与群级模型路由、独立工作负载配置。
- SQL 记忆存储、摘要与反思；可选 Embedding 检索，SQLite 使用内存向量，PostgreSQL 使用 pgvector。
- Skills ZIP 导入、按需加载与隔离沙箱脚本执行，以及 MCP 工具集成。
- 实例备份与还原、SQLite / PostgreSQL 存储、前置 Cloudflare Access 的 Docker 部署方式。

## 安装条件

- 源码构建：Go ≥ 1.27.3、Node.js 22、pnpm 10.33.0 和 buf；Make 构建还需要 Bash。
- 运行：默认 SQLite；选择 PostgreSQL 时由部署者提供数据库，启用向量检索前需安装并启用 pgvector。
- 模型服务、IM 上游、Cloudflare Tunnel / Access、外部沙箱和 stdio MCP 运行时按所用能力另行配置，不随源码提供。

固定版本安装与 Windows PowerShell 构建命令见[发布指南](https://github.com/GuaiZai233/FrostAgent/blob/v1.0.0/docs/releasing.md)；部署方式见[中文 README](https://github.com/GuaiZai233/FrostAgent/blob/v1.0.0/README_zh_CN.md)。这些固定版本链接在 tag 发布后生效。

## 从开发版本升级

- 当前数据库 Schema 为 v14。v7–v13 通过顺序 Migration 升级；低于 v7 或高于 v14 的数据库会被拒绝加载，不自动删除或重建。
- 旧 JSON 和 `.env` 运行数据不再自动加载，也不会自动迁移。`cmd/agent` 的 JSON 记忆工具不能代替 SQL 实例的备份还原。
- 升级前停止相关进程，备份完整 `data/` / Docker 应用卷、外部 PostgreSQL，以及外部凭据来源。实例 ZIP 会剔除密钥及凭据来源，不能作为整站回退备份。
- 实例 ZIP 还原会创建默认停用的新实例；启用前重新配置凭据和适配器。切换 SQLite / PostgreSQL 只加载目标库，不自动搬迁原库。
- 回退需恢复升级前的数据快照与旧程序；不能直接让旧程序连接已迁移的新库。同一 PostgreSQL 数据库只允许一个 FrostAgent 进程使用。
- 从旧 Caddy 部署升级时，按 README 停用旧 gateway，保留应用卷与 Compose 项目名，重新确认 Tunnel 回源、整个管理域名的 Access 策略与监听边界。

## 验证边界与已知限制

仓库 CI 包含 Linux / Windows 构建与测试、前端回归、Go 并发回归、真实 PostgreSQL 迁移测试，以及 Docker 本地网络和持久化 smoke。发布时仍须检查 tag 所指提交的实际运行结果；流水线存在不等于该提交已通过。

真实 IM 接入、真实模型与 Embedding 效果、Cloudflare Access 云端登录/策略以及 Docker Desktop 宿主机转发，不由这些 CI 结果证明，部署者需验证自己的集成环境。SQLite 向量在重启后重建；备份不包含向量索引。
