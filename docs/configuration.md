# 配置与数据

[返回首页](../README_zh_CN.md) · [English](configuration.en.md)

首次使用只需创建实例、配置模型并接入适配器；以下内容按需查阅。

## 人格与设置

- 在「人格设定」配置 Bot 名称、唤醒别名和系统提示词。
- Bot 服务端设置修改后，点击顶部「保存」统一应用；「还原」或离开页面会丢弃未保存更改。
- 灰色占位表示默认值或继承值；留空保存即可清除自定义值。
- 普通设置保存后自动应用；额外环境变量注入需重启 FrostAgent。旧 JSON 和 `.env` 不再作为运行配置加载。
- 模型密钥在「模型路由器」的 Endpoint 中配置，Coder 使用子智能体模型绑定。旧 `UPSTREAM_API_KEY`、`CODER_API_KEY`、`MAX_CONTEXT_CHARS` 和适配器选择开关不再作为常规设置提供。
- 计费价格使用非负整数最小单位：100 单位＝1 雪花＝0.01 元；安全倍率必须大于 0。

## 模型路由

「模型路由器」统一管理 Endpoint、模型、实例默认路由和群覆盖：

| 配置                                 | 生效范围                                       |
| ------------------------------------ | ---------------------------------------------- |
| 供应商地址、凭据、启停状态和模型目录 | 当前数据库的所有实例共享；未创建实例时也可配置 |
| 七类任务的默认模型、群模型覆盖       | 当前实例独立；群可继承默认模型                 |

发布后，新请求立即使用新配置，进行中的对话保留地址与凭据快照。若共享目录与实例路由只有一部分发布成功，页面会提示结果并保留剩余编辑供重试。删除实例不会删除供应商；仍被路由引用的模型不能删除。

## Embedding 记忆检索

1. 在「模型路由器」添加支持 OpenAI-compatible `/embeddings` 的模型，标记 `embedding` 能力。
2. 绑定实例或群的 Embedding 路由。
3. 在 Bot 服务端设置的「记忆设置」开启「启用Embedding」。

标签、摘要提取和反思保持不变，检索改用向量；索引随提取窗口和反思更新，缺失或失效时后台重建。工具支持自然语言 `query` 或 `tags`，优先 `query`，Bot/工具最多返回 20 条结果；网页仍分页。

- **SQLite**：向量只存在内存，重启后重建。
- **PostgreSQL**：管理员须先安装 pgvector，并在目标数据库执行 `CREATE EXTENSION vector`，否则不能启用。
- 关闭后恢复关键词检索，保留 PostgreSQL 向量；备份不携带向量。
- 「最大输入 Tokens」可选，使用保守 UTF-8 字节预算截断请求副本；明确超限的请求跳过处理，已保存原文不删除。

实现细节见[记忆设计](../.frostagent/whitepaper/memory.md)。

## 数据库与备份

默认使用 `data/frostagent.db`（SQLite）。在「设置 → 数据库设置」切换 PostgreSQL 时必须填写连接地址；选择保存在本地 SQLite 引导表中。同一个 PostgreSQL 数据库只允许一个 FrostAgent 进程使用。

**切换数据库只加载目标已有数据，不会迁移。** 需要搬迁实例时使用「设置 → 备份与还原」。设置、记忆、模型路由、MCP、示例对话、贴图元数据和群摘要存入 SQL；贴图图片仍存于实例目录，备份应用数据时也要保留这些文件。

备份与还原的边界：

- 可导出实例全量 ZIP、`setting.json` 和 `memory.json`；ZIP 的展开数据和压缩包均限 512 MiB。
- 导出会清空密钥及凭据来源，不包含 Embedding 向量。
- 全量还原创建一个**默认停用的新实例**；启用前重新配置凭据和适配器。
- 备份仅携带实例引用的供应商与模型。还原或复制时，相同定义复用已有共享凭据；冲突定义使用新 ID 和空凭据，并重映射导入实例的路由，不改写其他实例或已有共享凭据。

## 升级前必读

先备份完整应用数据、外部 PostgreSQL 和凭据来源；实例 ZIP 不含密钥，不能代替完整回退备份。回退须同时恢复旧程序和升级前的数据，不能直接用旧程序连接已升级的库。操作步骤见[升级与回退](releasing.md#升级备份与回退)，Docker 卷见 [Docker 部署](docker.md#升级与数据保留)。

- 旧版 JSON、`.env` 运行数据不会自动导入；替换旧版本前请自行备份。
- SQL 从 v7 基线按顺序、事务化升级；低于 v7 或高于当前程序支持版本的数据库原样保留并拒绝加载。
- v7–v10 的供应商目录升级会重映射冲突的 ID、名称和路由，旧表留作迁移存档。若人工改库造成重复的 Windows 凭据 Endpoint ID，升级会拒绝继续，不覆盖凭据。

Schema 开发规则和旧 JSON 群目录人工恢复见[开发指南](development.md)。

## 管理访问认证

普通构建的远程管理 API（设置、备份、日志、实例、数据库等）必须提供控制令牌：先在本机 Bot 服务端设置中配置「管理控制令牌」，再在网页「前端设置」填入相同值。

- `MCP_CONTROL_TOKEN` 优先于兼容的 `ADMIN_TOKEN`；`ALLOW_REMOTE_MCP_MANAGEMENT` 不能绕过管理鉴权。
- 本机回环访问默认免令牌；启用 `MCP_ENFORCE_LOCAL_TOKEN` 后本机也必须认证。
- 反向代理须保留公开 Host 或转发标识；若将 Host 改为本机并清除全部转发标识，必须启用 `MCP_ENFORCE_LOCAL_TOKEN`，避免远程请求误用本机豁免。

隔离 Docker 部署由前置 Cloudflare Access 认证，默认无需额外本地登录；它仍遵守显式开启的本机强制令牌。部署前阅读 [Docker 安全要求](docker.md)。
