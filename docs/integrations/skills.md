# Skills 技能包

Skills 将一组说明和资源组织在 `SKILL.md` 周围，让 Agent 按任务加载。FrostAgent 支持导入 Claude Code、Gemini CLI 等工具使用的技能文件格式，并以自己的会话、权限与沙箱机制执行。

## 导入和启用

1. 选择实例，打开「Skills → 导入 ZIP」。
2. 上传包含 `SKILL.md` 的 ZIP，检查发现的技能、资源和兼容性提示。
3. 导入后的技能默认禁用，确认内容和依赖后再启用。
4. 在真实对话中让模型按任务加载，或输入 `/skill-name 参数` 手动调用。
5. 在「会话与 Prompt」核对实际技能上下文，在日志检查工具结果。

支持 ZIP 根目录的 `SKILL.md`、`<技能名>/SKILL.md`、多个技能目录，以及 `.claude/skills/`、`.agents/skills/`、`.codex/skills/`、`.gemini/skills/` 或插件目录外层包装。只导入技能目录内的文件，目录外资源不会自动带入。

同批导入整体成功或失败；重复名称、嵌套技能根目录和已存在的同名技能会被拒绝。更新技能时，先保存需要保留的原包，再显式删除旧技能并导入新包，不会静默覆盖。

## 一个最小技能

创建以下目录，再压缩为 ZIP：

```text
greeting/
└─ SKILL.md
```

`SKILL.md` 内容：

```md
---
name: greeting
description: 按用户给出的称呼写一句简短中文问候。
---

使用参数中的称呼写一句友善问候：$ARGUMENTS
不要推断用户身份或保存个人信息。
```

启用后输入 `/greeting 朋友`。这个例子只有指令，不需要沙箱；导入或加载技能本身不会运行脚本。

## 加载与资源读取

启用技能的名称、简短描述和环境要求进入模型目录，完整指令由模型调用 `load_skill` 按需加载。一个会话最多保留 4 个活动技能，指令与普通历史分别维护，历史裁剪后仍可继续注入。

`read_skill_resource` 可读取已激活技能内最多 48 KiB 的 UTF-8 文本。二进制或更大资源可交给沙箱中的脚本使用。停用或删除后不再注入指令，后续资源读取和执行也会被拒绝；重置会话清除已激活技能。

`disable-model-invocation: true` 限制为手动激活；`user-invocable: false` 禁止手动调用。`$ARGUMENTS` 使用手动调用时提供的参数。

## 执行脚本

`run_skill` 将已校验资源放入当前会话隔离沙箱中的新目录，然后执行命令；`SKILL_DIR` 和 `CLAUDE_SKILL_DIR` 指向该目录。先配置并开启[隔离沙箱](./sandbox)，关闭或不可用时执行失败，不回退到宿主机。

沙箱需要 `mktemp`、`printf`、Python 3，以及脚本需要的解释器和依赖。FrostAgent 镜像内安装了哪些工具，不决定外部沙箱具备哪些依赖。ZIP 中的可执行文件只保留可执行标记，在沙箱恢复为 `0755`，可用 `./scripts/task.sh` 运行。

资源准备和命令执行共享超时预算，准备失败或超时后不会继续运行脚本。结果保留退出码、超时状态和有长度限制的 stdout / stderr。沙箱命名空间包含实例和会话，会话释放时清理其资源。

## 格式兼容与权限

识别标准 `name`、`description`、`compatibility`。部分 Claude 风格包缺少名称时可用所在目录名，缺少描述时使用首个非空指令行。

`allowed-tools`、`context`、`agent`、`model`、`hooks`、`mcp_servers`、`paths`、命名 `arguments` 等专属字段只保留并显示兼容性警告，不按原工具的语义执行。Shell 上下文插值也不会执行；依赖这些机制的包需自行适配。

技能元数据不能授予工具权限，所有调用仍经过现有安全网关。ZIP 保存在 SQL 中，不解压到宿主机；拒绝路径穿越、绝对路径、反斜杠路径、符号链接、特殊文件及大小写冲突。

## 限额与备份

| 项目                              | 限额          |
| --------------------------------- | ------------- |
| 上传 ZIP                          | 16 MiB        |
| 解压后的本批内容 / 每实例全部资源 | 各 32 MiB     |
| 单个技能                          | 8 MiB         |
| ZIP 成员 / 每实例技能             | 1024 / 100    |
| `SKILL.md`                        | 32 KiB，UTF-8 |

技能按实例隔离，保存在 SQL 中，包含资源字节和可执行标记。全量实例 ZIP 包含可选 `skills.json`；没有该文件的旧存档仍可还原。仅设置导出或「覆盖配置」不包含技能。数据库结构使用 Schema v14，参见[升级说明](../operations/upgrading)。
