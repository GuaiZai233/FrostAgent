# Alcyone 计费

Alcyone 是可选的外部计费服务。`BILLING_ENABLED` 默认 `false`，未启用时无需配置。它独立于模型供应商自身的 API 账单。

## 配置

| 设置                                   | 范围 | 默认 / 用途                        |
| -------------------------------------- | ---- | ---------------------------------- |
| `ALCYONE_BASE_URL`                     | 全局 | 启用时默认 `http://127.0.0.1:8081` |
| `ALCYONE_SERVICE_TOKEN`                | 全局 | 服务通信凭据                       |
| `ALCYONE_TIMEOUT`                      | 全局 | 默认 `5s`                          |
| `BILLING_ENABLED`                      | 实例 | 默认 `false`                       |
| `BILLING_MAX_OUTPUT_TOKENS`            | 实例 | 预扣输出预算，默认 2048            |
| `BILLING_SAFETY_MULTIPLIER`            | 实例 | 输入估算安全倍率，默认 1.2         |
| `BILLING_PROMPT_PRICE_PER_MILLION`     | 实例 | 每百万输入 Token 价格              |
| `BILLING_COMPLETION_PRICE_PER_MILLION` | 实例 | 每百万输出 Token 价格              |

先部署并验证 Alcyone，再填写全局服务连接和实例计费参数。SQL 模式保存后自动应用，必要时重建相关实例运行时；检查保存结果和服务日志。价格按当前实际计费约定填写。

## 结算行为

模型请求使用预留 / 结算流程，实际使用量和估算预算是不同概念。服务连通、用户账户、余额与结算结果需要在真实平台验证，不能仅凭配置保存成功判断计费可用。

主动回复和 `mock=true` 模拟对话不参与正常的用户扣费路径。模型供应商的真实请求仍可能产生费用，开启后台压缩、记忆提取和安全审查也会增加模型调用量。

排查时检查计费日志、服务通信凭据、请求超时和用户身份映射；不要把 Token 或用户账单明细贴入公开日志。
