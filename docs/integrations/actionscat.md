# ActionsCat

[ActionsCat](https://github.com/actionscat/actionscat) 是外部自动化平台。FrostAgent 可以向它分发事件、调用动作并查看运行结果；动作也可以通过 FrostAgent 消息接口向聊天平台回传结果。

## 配置连接

在当前实例设置以下值，SQL 模式保存后自动应用，必要时重建运行时：

| 设置                          | 用途                             |
| ----------------------------- | -------------------------------- |
| `ACTIONSCAT_ENDPOINT`         | ActionsCat 核心服务地址          |
| `ACTIONSCAT_MANAGEMENT_TOKEN` | 管理 API 凭据                    |
| `ACTIONSCAT_DISPATCH_TOKEN`   | 事件调度凭据；留空复用管理 Token |
| `AGENT_MAX_ITERATIONS`        | 多步骤工具循环上限，默认 35      |

进入「ActionsCat」检查网络联通和认证状态，再查看动作、版本、构建与运行日志。服务地址使用核心 API 地址；它与沙箱网关、FrostAgent HTTP 地址属于不同用途。

## 运行一个动作

动作需要启用、存在激活版本并存在激活构建，才能执行。只有元数据而没有构建产物的动作会显示未构建 / 未激活。

在控制台可以手动触发并检查输入、stdout / stderr 与状态。对话工具可以让模型查询动作或执行可运行任务；创建动作、版本、构建、激活和部署等管理写操作需要当前实例配置的管理员身份。

对话执行自定义环境变量不能使用 `ACTIONSCAT_` 受保护前缀，避免伪造受信运行上下文。直接对话模拟模式会拦截执行与变更，不创建真实任务。

## 消息回传

外部动作通过实例明确的入口发送结果：

```text
POST /instances/<实例ID>/api/v1/messages/send
```

配置消息接口的认证 Token，并携带相应认证头；无 Token 时接口拒绝发送。消息还需要正确的目标平台、会话类型、目标 ID 和可用适配器。接口格式见 [API 入口](../reference/api)。

定时动作需要保留可信的目标会话和适配器上下文，避免用全局默认实例猜测回传对象。不要把动作的内部凭据或运行环境完整交给模型；当前模型结果 DTO 会过滤敏感运行环境。

## 排查

- **不健康**：核对核心服务地址和网络。
- **未认证**：核对管理与事件调度 Token。
- **不能执行**：检查启用、激活版本与激活构建。
- **结果没有投递**：检查消息接口认证、实例状态、目标和适配器回执。
- **循环提前结束**：检查迭代上限和工具失败，不通过无限提高上限隐藏故障。
