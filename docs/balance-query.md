# 原生额度查询与工具开关

在实例概览的「已注册工具能力」中，每个原生工具卡片右上角都有独立开关。
关闭后，工具会从模型可用工具列表中移除，后续调用也会被拒绝。配置按实例保存，立即生效。
未配置或依赖未启用的工具仍可在卡片中查看；开关不会绕过其原有权限和依赖检查。
MCP 工具继续使用 MCP 页面已有的独立开关。

点击 `balance_query` 卡片可配置额度请求；没有可配置参数的工具不会打开配置弹窗。
默认模板：

```sh
curl https://api.deepseek.com/user/balance \
  -H 'Authorization: Bearer {{API_KEY}}'
```

可配置工具会在工具名下方显示「可配置」。curl 中使用 `{{API_KEY}}` 占位。
勾选「复用已有配置的 API Key」后，选择一个已启用且已配置密钥的 Provider，
FrostAgent 会在每次查询时读取该 Provider 当前已发布的 API Key，无需再次填写。
这里只保存 Provider 引用，不复制密钥；Provider 更新密钥后自动生效，未发布的草稿不会使用。
Provider 被停用、删除或密钥不可用时，工具停止提供给模型，旧调用也会失败，不回退到其他凭据。
取消复用可改为手动填写独立 API Key；从 Provider 切回手动模式时需要填写密钥。
手动密钥保存后不会回填到弹窗；留空保留现有手动密钥。
未配置密钥时，`balance_query` 不会提供给模型。

支持管理员指定 HTTP/HTTPS 端点，包括内网和本机地址；请只填写可信的额度服务。
支持 GET/POST、`--url`、`-X`/`--request`、`-H`/`--header`、`-d`/`--data`、
`--data-raw`、`--data-binary`、`-G`/`--get`、`-s`/`--silent`、`-S`/`--show-error`。
密钥占位符可用于请求头、查询参数或请求体。模板不执行 shell，不读取文件，
不支持代理、跳过 TLS 验证或重定向等选项。

模型只能调用 `balance_query({})`，不能覆盖 URL、参数、请求头或密钥。
FrostAgent 在发送 HTTP 请求时注入凭据，仅将接口的原始响应正文交给模型；
非 2xx 的响应正文也保留。请求超时为 15 秒，正文上限为 60 KiB。
重定向、无效文本、超大响应和含有密钥回显的响应会被拒绝；请求 URL、请求头、
密钥和底层网络错误不会作为工具错误返回给模型。

查询配置和手动密钥保存在该实例现有的设置存储中，不会导出到不包含凭据的 `setting.json`。
复用模式中的密钥继续由 Provider 凭据存储管理，前端只获取 Provider 名称、ID 和可用状态。
