# 实例启动与资源生命周期

`Manager.New` 先恢复注册表和复制事务，为每个实例建立管理条目。正常启动时，已启用实例直接经过 `Enable` 构建一次运行中的 runtime；停用实例构建一次已取消的管理 runtime，继续提供配置和状态接口。正在删除或路径恢复失败的实例不启动。

启用失败时沿用 `Enable` 的失败回退：停止失败 runtime，尽可能保留读取最新配置的停用管理 runtime，并记录错误。配置损坏不会阻止健康实例启动，损坏配置仍能经管理接口修复后重新启用。这个异常回退可能再次尝试构建，不属于正常启动的重复初始化。

启停、重启和 `Manager.Close` 继续通过现有的 `Runtime.Stop` 与 MCP 生命周期释放资源；已经运行的实例重复启用不会重建。回归测试包装真实 runtime 构造器，统计两个启用实例与一个停用实例的构建次数，同时覆盖停用配置修改、启停取消及损坏配置修复。真实平台连接重连与长期负载资源观测属于集成验证。
