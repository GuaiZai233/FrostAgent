# 主动感知

主动感知会不定期向 Bot 自动注入提示词，使其具备主动给用户发送私聊消息、主动开启话题的能力。在「Bot 服务端设置 → 主动感知」启用；默认关闭，与收到群消息时按概率触发的「主动回复」分别配置。

## 活跃阈值

活跃阈值格式为 `30m - 2h`，两端使用以 `m` 或 `h` 结尾的正数时长，下限不能大于上限。每个符合范围的会话独立在区间内随机选择下一次触发时间。普通聊天消息不重置计时；正在对话时，Bot 按提示继续参与原话题。

阈值约束逻辑触发的间隔。实际发送取决于模型输出、静默工具、安全检查和平台连接。单个会话的主动感知不会并发执行；前一轮仍在执行时等待它结束。

仅在实例启用且存在明确可用的真实发送连接时计时。关闭功能、移出白名单或发送连接不可用时取消该会话的待触发计划；重新允许、重载实例或重启进程后重新随机计时，不补发停机期间的触发。正在执行的轮次在发送前重新检查总开关、白名单与会话重置状态。

## 白名单

私聊、群聊分别配置白名单开关和列表，与主动回复一致：开启白名单后仅列表中的目标可以触发，开启但列表为空时不会触发；关闭白名单时，范围为当前实例已知的对应会话。群档案保存的已知群可在重启后恢复，私聊名单中的用户可在没有新入站消息时创建会话。普通私聊历史仍遵循现有会话生命周期。

QQ / OneBot / aiocqhttp 使用裸 ID 或带平台前缀的 ID；其他平台必须使用 `platform:ID`。私聊与群聊即使 ID 相同也互相隔离。网页模拟对话不加入主动感知范围。

发送优先使用最近观察到该会话的适配器；尚未观察到路由时，QQ 仅在一个适配器明确可用时选择它，其他平台经 AstrBot。QQ 的存储身份和白名单别名统一为 `qq`，在 AstrBot 发送边界显式映射为其 QQ 传输标识 `aiocqhttp`，冷启动不依赖新入站消息恢复该标识。单个适配器存在多个真实连接时不会广播发送。OneBot 以平台 ACK 确认发送；AstrBot 沿用 socket 写入确认的现有边界。

## 提示词与上下文

私聊提示词：

> 此为触发主动陪伴逻辑的系统提示。此触发不关联任何一条具体消息。你需要结合过往的聊天历史，主动询问或关心用户。如果正在进行对话请补充你的想法或继续参与讨论，不要转移话题；如果距离上一次对话较久，可以开启新话题。

群聊提示词：

> 此为触发主动陪伴逻辑的系统提示。此触发不关联任何一条具体消息。你需要结合过往的聊天历史，在群里发送水群内容，可以具体到某一位群友（艾特请调用send_message工具）也可以根据总compact内容延续或启动新话题。如果群内正在进行对话请参与讨论。

提示词作为临时系统消息注入，附带当前时间和上次会话活动时间。私聊使用已有对话历史；群聊使用当前 compact 总结和未压缩群消息，与普通群回复共用运行时的条数限制（`GROUP_COMPACT_BUFFER_SIZE`）和字符限制（`GROUP_RAW_CONTEXT_MAX_CHARS`），继续遵守群聊 compact 白名单。不会伪造用户输入或将定时提示写入用户聊天历史；确认发出的回复进入公共历史，群回复也进入 compact 缓冲。

主动感知沿用主动回复的工具允许范围、无用户扣费和错误静默规则；`send_message` 单独限于当前会话的文本、当前群已知成员的原生艾特，不支持切换会话、引用不存在的触发消息、媒体或表情包。群触发不借用任何群友的安全身份，私聊继续检查接收用户的访问状态。原有主动回复仍保持引用具体消息后发送文本的权限。

## 设置与存储

| 设置 | 含义 |
| --- | --- |
| `ENABLE_PROACTIVE_AWARENESS` | 总开关，默认 `false` |
| `PROACTIVE_AWARENESS_INTERVAL` | 活跃阈值，默认 `30m - 2h` |
| `ENABLE_PROACTIVE_AWARENESS_PRIVATE_WHITELIST` | 私聊白名单开关 |
| `PROACTIVE_AWARENESS_PRIVATE_WHITELIST` | 私聊用户列表 |
| `ENABLE_PROACTIVE_AWARENESS_GROUP_WHITELIST` | 群聊白名单开关 |
| `PROACTIVE_AWARENESS_GROUP_WHITELIST` | 群聊列表 |

配置使用现有实例设置存储与备份机制，计时计划不持久化。群名称写入现有群档案，无新增表或 migration；设置页从持久化档案恢复名称，查询失败保留旧名称，成功观察到新名称后覆盖。
